# Lunar Soft-Landing Guidance and Control

A MATLAB/Simulink academic project exploring guidance and control during a simulated lunar descent.

The project focuses on trajectory shaping, thrust-angle control and spacecraft mass variation during descent.

## What I Worked On

- Lunar descent trajectory modelling.
- Polynomial trajectory shaping.
- Thrust-angle control.
- Propellant mass variation.
- Numerical simulation using RK4 integration.
- Sensitivity analysis.

## Tools & Methods

MATLAB , Simulink , Guidance and Control , Orbital Mechanics , Numerical Integration
